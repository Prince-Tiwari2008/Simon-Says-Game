# 🎮 Simon Says Game
A fun and interactive memory-based game built using **HTML, CSS, and JavaScript**. Test your memory by remembering and repeating the color sequences as the difficulty increases with each level.

## ✨ Features :-
- **Interactive Gameplay:** Click the colored buttons to repeat the displayed sequence.
- **Progressive Levels:** Each level introduces a new color to the sequence.
- **Score Tracking:** Keep track of your current game progress.
- **High Score:** Automatically saves your highest score using LocalStorage.
- **Game Over Animation:** Cinematic game-over screen with visual effects.
- **Start & Restart:** Easily start a new game whenever you're ready.
- **Responsive Design:** Optimized interface for different screen sizes.
- **Modern UI:** Gaming-inspired background, glowing effects, and interactive button styling.

## 🛠️ Technologies Used :-
- **HTML5** – Structure of the game.
- **CSS3** – Styling, layouts, transitions, and animations.
- **JavaScript** – Game logic, DOM manipulation, event handling, and LocalStorage.

## 🎯 How to Play :-
1. Click the **START GAME** button to begin.
2. Watch the color that flashes on the screen.
3. Click the corresponding colored button.
4. Remember the previous sequence as new colors are added.
5. Repeat the complete sequence correctly to advance to the next level.
6. Selecting an incorrect color ends the game.
7. Try to beat your highest score!

## 💾 Data Storage :-
The game uses browser **LocalStorage** to save the highest score, allowing it to remain available even after refreshing the page.
